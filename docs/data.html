Data

All solmaps data is open under CC BY 4.0. Each dataset below sits at a fixed address, so a script, an app or a game can fetch exactly what it needs without a server of its own. Every example on this page runs in our tests against the published files.

What is where

Transfer data v0.1Every transfer option between 30 bodies for every departure day from 1 November 2026 to 31 December 2100, flights up to 100 years: 235.7 million options with flight time, the excess speeds at both ends, revolutions around the Sun and closest distance to the Sun. Examples

Earth to Mars on one day, in the browser (JavaScript)

const day = '2031-04-09';
const url = `https://huggingface.co/datasets/Deep-Space-Strategy/solmaps-transfers/resolve/main/api/v1/snapshot/${day.slice(0, 4)}/${day}.json`;
const snap = await (await fetch(url)).json();
const [classicDv, classicDays] = snap.routes.earth.mars;
console.log(`Earth to Mars on ${day}: ${classicDv} km/s, ${classicDays} days`);

All options of a route, in Python

import pandas as pd
url = 'https://huggingface.co/datasets/Deep-Space-Strategy/solmaps-transfers/resolve/main/data/earth.parquet'
df = pd.read_parquet(url, filters=[('target', '==', 'mars')])
best = df.loc[df.groupby('departure')['vinf_departure_kms'].idxmin()]
print(len(df), 'options from Earth to Mars;', best.head())

The Parquet file holds every option from Earth (about 100 MB); pandas downloads it once. The columns give the excess speeds; the cost at a parking orbit follows from them as the datasheet describes.

Queries without a download

Hugging Face runs a query service for public datasets (the Dataset Viewer API), which would answer filters such as one route on one day without any download. In our tests on 11 November 2026 it did not yet answer for this dataset ("server busier than usual"), so this page shows no example for it; the snapshot files and the Parquet files above work without it.
